## Audio chain

- Audio mode: **i2s** (`/etc/assistant/alsa/i2s.conf`).
- Softvol `XVF3800 SoftMaster`: **39%** (99/255, limits 0-255) at capture time.
- Detector input: `audio --input-channel 0` = ALSA left = `AUDIO_MGR_OP_L 8 0`
  (final processed beam).

## Services / harness wiring (IMPORTANT)

- `audio.service`: **active**. Binds **consumer `0.0.0.0:50051`**, producer
  `0.0.0.0:50052` (NOT 8080). Also `--mixer-name "XVF3800 SoftMaster"`,
  `--tts-volume-boost 15`.
- `agent-edge.service`: **failed/stopped** -> the single consumer slot is already
  free, so `fake_agent_edge.py` can connect without stopping anything.
- `spotifyd.service`, `mpv.service`: active (needed for `--keep-music` barge-in).
- `spotify-control`: `0.0.0.0:3001`. `led_controller`: `0.0.0.0:3000`.

### Corrected harness invocation for this deployment

The plan/harness docstring default to port 8080; this build uses 50051:

```bash
# on the Pi (you speak the prompts):
cd ~/agent-edge-rs/experiments/xvf3800-ww
./fake_agent_edge.py --label <cond> --consumer 127.0.0.1:50051 \
    --keep-music --spotify-control http://127.0.0.1:3001 \
    --outdir data/<session>     # add --no-stt for capture-only
```
